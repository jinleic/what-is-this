## 0. What changed the picture this wave

Until wave 17 the algebra program was a sequence of *individual* exact classifications: `2x3` at
wave 15, `2x4` at wave 16, `2x5` at wave 17, each an independent multi-hour computation, with an
all-`L` containment theorem and an unproved saturation step. The `3x3` layer was described as "a
different regime" because its local-term closure saturates `65535 = 2^16 - 1`, a number with no
apparent relation to the ladder dimensions `56, 1056, 16256, 262656`.

Mid-wave-18 that description turned out to be wrong, and the mechanism is elementary. Order the
layer's vertices along a Hamiltonian **path** and apply Jordan-Wigner in that order, introducing
`2n` Majoranas. Then:

- every single-site term and every *path* bond is a Majorana bilinear, and consecutive bilinears
  generate all of `so(2n)`, because `[g_a g_b, g_b g_c] ~ g_a g_c` and a connected chain of index
  pairs reaches every pair;
- a *non-path* edge joining path positions `p < q` is a single Clifford monomial of grade `2(q-p)`;
- if the graph is **bipartite** then every edge joins opposite colours, so `q-p` is odd and every
  non-path edge has grade `= 2 mod 4`;
- the span of all grade-`= 2 mod 4` monomials is closed under brackets, because commutators of
  grades `a,b` live in grades `a+b-2j` with `j` odd, and `a = b = 2 mod 4` gives `a+b = 0 mod 4`.

That span is exactly the `-1` eigenspace of Clifford reversal in the even Clifford algebra, since a
grade-`k` monomial reverses with sign `(-1)^(k(k-1)/2)`, which is `-1` precisely for `k = 2 mod 4`.
So it is the Lie algebra preserving the spinor bilinear form on each half-spin space, and the form is
symmetric when `n = 0 mod 4` and alternating when `n = 2 mod 4`. With `n = 2L` that is the observed
even-`L`/odd-`L` `so`/`sp` alternation, with no combinatorics at all.

The dimension prediction is `sum_{k = 2 mod 4} C(2n,k)`, minus one when `n` is odd because the top
monomial then lies in the class and is a scalar. In closed form
`2^(2n-2) - (-1)^(n/2) 2^(n-1)` for even `n`, and `2^(2n-2) - 1` for odd `n`. It matches every value
the repository had computed independently:

| graph | `n` | prediction | previously certified |
|---|---:|---:|---:|
| `2x2` | 4 | 56 | 56 |
| `2x3` | 6 | 1056 | 1056 |
| `2x4` | 8 | 16256 | 16256 |
| `2x5` | 10 | 262656 | 262656 |
| `3x3` | 9 | 65535 | 65535 |

Five for five, including the one layer that was supposed to be a different regime. `3x3` is not a
different regime; it is the same statement at odd `n`, where the central top monomial is removed.

**Why this is the highest-leverage direction.** It converts a family of expensive individual
computations into one structural theorem whose hypotheses are graph-theoretic (bipartite, has a
Hamiltonian path, has at least one non-path edge) and whose conclusion is an exact dimension and an
exact classical type. Every simple-cubic layer graph is bipartite and Hamiltonian-path-admitting, so
the theorem, if it survives, covers **all** layer sizes at once. Status: dispatched as front
`CliffordGradeClass` with the obligations enumerated; treat it as `[CONJECTURE]` with five confirming
data points until that front reports.

## 1. Ranked directions by leverage

Leverage here means: expected strength of the resulting statement, divided by the cost of the
decisive experiment. Ordered by that ratio, not by ambition.

### 1.1 The general grade classification (highest leverage, cheap)
Discussed above. The decisive experiments are small: a non-bipartite falsification test, the
grade-generation lemma for a single non-path edge, and one new prediction at `n = 12`
(`4192256`, shared by `2x6` and `3x4`). All are cheap because the grade characterization avoids
materializing a four-million-element closure.

**If it lands**, the immediate corollary is an all-size, isotropic, genericity-free free-fermion
no-go: `dim g` is about `4^(n-1)`, the Gaussian bound is `dim <= m(2m-1)` for `m` modes, so the local
terms of any such layer are not Majorana-quadratic in any basis, and any Gaussian realization needs a
mode count exponential in `n`. That is qualitatively stronger than the existing all-size Theorem F in
three respects: it needs no genericity, it holds at the physical isotropic point, and it is exact
rather than off-a-hypersurface. It is weaker in one respect that must be stated honestly: it
constrains the *algebra generated by the local terms*, not the spectrum of the transfer operator, so
it does not by itself exclude a Gaussian *spectrum* arising some other way. The two routes are
complementary and should be presented as such.

### 1.2 The `W_L` law (wave 19: a conjectured exact law, plus an unconditional bound)
The certified sequence is `W_L = 0, 2, 10, 66, 364, 1822, 8586` for `L = 3..9`, with
`K_L = (2^(2L-1)+3*2^L)/4`. Wave 19 identified an exact law from the `L=9` sector vector and then
held it out against every other certified quantity:

```text
dim U_L = (C(2L,L) + 2^L)/2 - [4 divides L],      W_L = K_L - dim U_L.
```

This reproduces `14, 42, 142, 494, 1780, 6562, 24566` at `L = 3..9`, hence all seven `W_L` values,
with zero fitted parameters, and predicts `W_10 = 38950`, `cyclic_10 = 92890` as a falsifiable
test. It stays `[CONJECTURE]`: identified structurally, validated on holdout, not proved.

Two consequences matter. First, **the bound I originally proposed is impossible**: since
`dim U_L ~ 4^L/(2 sqrt(pi L))` while `K_L ~ 4^L/8`, the ratio `W_L/K_L` tends to `1`, so no bound
`W_L <= (1-c) K_L` with constant `c > 0` can hold. Do not retry it. Second, under the law
`K_L - W_L >= 2^L` for every `L`, so the long-standing `D_(2L) >= 2^L` conjecture would follow; that
implication is a conditional theorem worth recording.

The unconditional result is better news than the conjecture: `dim g_L >= Q(L)`, where `Q(L)` counts
partitions with `|lambda| + 2 len(lambda) <= L`, and `Q(L) > 8L^2 - 2L + 1` for all `L >= 32`. That
plus exact certificates at each smaller `L` assembles into an all-`L` free-fermion no-go for the
ladder transfer generators. The right all-`L` object is a direct lower bound on the dimension, not a
bound on `W_L`.

### 1.3 The isotropic gap in Theorem F (landed as a split verdict in wave 18)
Theorem F is all-size but anisotropic; Theorem G was isotropic but covered only eight named graphs.
Wave 18 resolved the two halves separately, and the verdict is a clean split
(`proofs/isotropic_allsize.md`, ledger `H440`-`H445`).

- **The core piece SUCCEEDS.** Three new isotropic cores are certified strictly above their own
  Gaussian pair-product ceiling at `t=1/3`, at both primes `1000003` and `2000003`: the paw
  (`r_Q >= 119 > 65`), the five-site branch-length-`(2,1,1)` tree (`417 > 211`), and the open `2x2`
  grid with a pendant (`475 > 211`). Controls behave as they must: the bare claw `K_{1,3}` only
  reaches its ceiling (`65 = 65`) and the star `K_{1,4}` falls below it (`147 < 211`), which is
  exactly why the bare claw seed never sufficed. With the monic upgrade each of the three is
  non-Gaussian at all but finitely many isotropic couplings, with exceptional-degree bounds
  `913920`, `17677440`, `19641600`.
- **The decoupling piece FAILS, exactly.** The Lemma-5 graph-piece tensor factorization is provably
  not an identity on the isotropic curve: the necessary crossing-factor minor is `q(t)^(2c) - 1`,
  whose cleared numerator `(1+t^2)^(2c) - (2t)^(2c)` is strictly positive for `0 < t < 1`. And the
  natural localizing family is provably too small: for `G_m = K_{1,3}` union `m` isolated vertices,
  `r(G_m) <= 136(2m+1) < 3^(m+4) - 2^(m+4)` for every `m >= 3`, i.e. linear growth against an
  exponential ceiling.

So the isotropic all-size spectral theorem is still `[UNRESOLVED]`, but it is no longer vaguely open:
the obstruction is named and certified. What is needed is a **non-localizing** isotropic argument, for
instance a certified endpoint or Puiseux-germ count, rather than another decoupling identity. Note
that if §1.1 lands, the *algebraic* isotropic all-size statement follows by a completely different
route, which lowers the urgency of the spectral version without replacing it.

### 1.4 The upper endpoint of the critical interval (highest value, lowest probability)
The lower endpoint has moved four times; the upper endpoint has not moved at all, and both incumbent
routes are certified dead: the two-point infrared/GKS class is exactly optimal at the incumbent with
an `O(1/L)` torus LP floor, and the plain Peierls head-plus-tail certificate provably cannot close
(`K* = 0.2558326` sits `0.003102` above, tail mass `1.65288 > 1/2`). Any improvement must use
genuinely four-point or paired-momentum information, or exactly evaluated random-current
inequalities. This is the one direction where a negative result is nearly as valuable as a positive
one, because each exactly refuted class permanently narrows where the answer can come from.

### 1.5 Series length (mechanical, resource-bound)
High-temperature `v^30` and low-temperature `x^60` are not mathematically blocked; they are blocked
by a contended host, and `x^62` additionally needs a 30-spin cross-section, i.e. one guard lift.
These extend the exact base and can refute more closed-form ansatzes, but no series length settles a
structural question, and the completed negative frontiers are already finite-ansatz results. Treat
this as maintenance, not breakthrough.

### 1.6 Kac-Ward branch `11111` (bounded, now sharply scoped)
Emptiness cannot be certified by Nullstellensatz at any degree, because the construction ideal is
proper over `Q`. So the decision must be structural or by exhaustive holdout. Wave 18 established
that no orbit quotient is available either: on the diagonal-normalized thin chart the only sound
action on the `4^7` section set is the identity, so the exact orbit count is `16384`. What remains is
a complete census plus a per-point holdout, which a vectorized exact character evaluation makes
feasible. Even a complete `F_5`-unit census does not close the branch over `Q`; non-unit valuations
and chart-degenerate points remain.

## 2. Directions deliberately NOT recommended

Recording these saves future waves from re-deriving dead ends.

- **More symmetry compression for `s <= 6` extensive charges.** Both routes are closed negatively:
  the octahedral/orbit route by a cap lemma (46.93x compression still reaches only 2.63% of the
  required pivots) and the second route by rank non-additivity over orbit blocks. A new *structural*
  reduction is needed, not a better rank computation.
- **Another ladder rung.** `W_8 = 1822` and `W_9 = 8586` are both certified. More rungs add data
  points to a sequence whose law is the actual question.
- **A bound `W_L <= (1-c) K_L` with constant `c`.** Impossible: under the wave-19 law `W_L/K_L`
  tends to `1`. Bound the dimension directly instead.
- **`ad_A` Vandermonde grade separation for the two-generator algebra.** Refuted exactly: every edge
  monomial, path bond or chord, occupies one Majorana at each endpoint and both at interior sites, so
  its `ad_{iA}` spectrum is `{0, ±4i}` regardless of Clifford grade. Vandermonde therefore recovers
  only the three global components of `B`, never an individual chord or `B_high`.
- **Group rigidity for the isotropic spectral question.** Refuted exactly by a one-mode witness:
  `exp(aH)exp(bX)` is pointwise conjugate into `Spin(2,C)` on an open set while `<H,X>_Lie = sl(2,C)`,
  so a varying conjugator absorbs the transverse derivative. A large fixed Lie algebra excludes only a
  parameter-independent quadratic basis, never pointwise varying Gaussian conjugacies.
- **A universal two-generator dimension threshold over all branching bipartite graphs.** False:
  `K_{2,3}` gives `44 < 45` and `K_{3,3}` gives `63 < 66`. High graph symmetry makes the two SUMS
  generate an unusually small algebra. Target the grid family instead, where every certified value
  clears its ceiling.
- **More Dolan-Grady deformations inside the invariant supports `F1`-`F4`.** Both varieties are
  simultaneously empty for the minimal orbit basis, with all saturations trivial.
- **Nullstellensatz certificates for Kac-Ward branch `11111`.** Provably impossible at any degree.
- **Lee-Yang edge exponents at accessible sizes.** Provably non-identifiable: `sigma = 1/2` and
  `-1/4` both fit the exact data. A better estimator or a rigorous no-earlier-root argument is
  required; more cube sizes are not.
- **Fitting a formula to a short exact sequence.** The program has one withdrawn theorem from
  substituting a bound into the wrong side of an inequality; that is the standing reminder.

## 3. The methodological lesson worth institutionalizing

The grade classification was not found by more compute. It was found because one front was asked for
an *explicit independent family* to lower-bound a dimension, and the natural family turned out to
have a closed-form count that matched the upper bound. Two process features made that possible: the
containment theorem had already pinned an exact upper bound, so a matching lower bound was
immediately recognizable as a classification; and fronts report intermediate structure over `hub`
instead of only final results, so a construction found for one purpose was reused for another within
minutes.

The generalizable rule: **when an exact upper bound exists, prefer constructing an explicit lower
bound over refining the upper bound.** A matching pair is a theorem; a tighter upper bound is only a
better estimate. Corollary for tooling: any front that produces a dimension formula should be asked
to test it against every already-certified value in the repository before claiming novelty, because
that is exactly the check that turned `3x3` from an anomaly into a confirmation.
