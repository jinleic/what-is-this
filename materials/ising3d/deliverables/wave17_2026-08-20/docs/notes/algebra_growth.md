# Depth-graded growth of the two-generator Ising algebra

## 1. Question and conventions

For a layer graph \(\Gamma=(V,E)\), this experiment studies

\[
 A=\sum_{v\in V}X_v,\qquad B=\sum_{(u,v)\in E}Z_uZ_v,
\]

and the Lie algebra generated by the **two sums** \(A,B\), not the much larger algebra generated
by their individual Pauli terms.  Put

\[
 F_1=\operatorname{span}\{A,B\},\qquad
 F_{k+1}=F_k+\operatorname{ad}_A(F_k)+\operatorname{ad}_B(F_k),\qquad D_k=\dim F_k.
\]

The span of generator-left-nested brackets of length at most \(k\) is exactly \(F_k\).  By the
Jacobi identity it is also the span obtained from arbitrary bracketings.  Consequently every
reported \(D_k\) is a rigorous lower bound on the total algebra dimension.  If
\(D_{k+1}=D_k\), then \(F_k\) is invariant under both adjoint maps and the algebra has saturated.
The JSON profiles include that final repeated value when saturation is proved.

All rank computations use the Pauli convention in `notes/CODE_API.md` and exact arithmetic over

\[
 p_1=2^{31}-1=2147483647,
 \qquad p_2=2147483629.
\]

Every Pauli commutator is divided by 2.  This replaces the structure constants \(0,\pm2\) by
\(0,\pm1\) and changes no span because 2 is invertible modulo either prime.  A nonzero minor
modulo \(p\) is a nonzero integer minor, so every modular rank is a **rigorous lower bound** on the
rank over \(\mathbb Q\).  Agreement at two primes is a strong cross-check, but is not by itself a
deterministic upper-bound certificate over \(\mathbb Q\).

## 2. Exact reductions used by the implementation

`experiments/e20_algebra_growth.py` uses four reductions.  None is heuristic.

1. **DLA support columns.**  Starting with every Pauli term in \(A,B\), close the support under
   anticommuting XOR with an individual generator term.  No bracket of \(A,B\) can leave this set.
2. **Global spin flip.**  Every bracket commutes with \(S=\prod_iX_i\).  In the binary Pauli
   encoding this means that the \(Z\)-mask has even parity.  Odd-\(Z\)-parity columns are absent.
3. **Point group.**  Both generators are fixed by every automorphism of the layer graph, hence so
   is every bracket.  Coefficients are constant on Pauli-string orbits.  Orbit sums therefore form
   an exact, smaller column basis: order 2 for an open chain, dihedral order \(2n\) for a ring,
   order 4 for a nonsquare rectangle, and order 8 for a square.
4. **Four grading blocks.**  For \(Q_{(a|b)}=X^aZ^b\), define
   \(r=|a|\bmod2\) and \(q=a\mathbin\cdot b\bmod2\).  Every generated row is homogeneous in
   \((r,q)\).  The map \(\operatorname{ad}_A\) toggles both bits and
   \(\operatorname{ad}_B\) toggles only \(q\).  Dense elimination is therefore split into four
   disjoint exact blocks.

Dense rows are stored as `int32`.  Products and accumulations use `int64`; the assertion
\(p^2<2^{63}\) makes every modular multiply overflow-safe.  The Mersenne prime uses two exact
31-bit folds instead of integer division.  The sparse engine stores orbit coordinates in Python
integer dictionaries and records both a conservative 96-byte-per-entry estimate and the observed
peak RSS.

The depth algorithm keeps an echelon basis for \(F_k/F_{k-1}\) as a frontier.  It applies
\(\operatorname{ad}_A,\operatorname{ad}_B\) only to the newest frontier, so it computes all
\(D_k\) without enumerating exponentially many bracket words.

## 3. Main results

### 3.1 One-dimensional controls

The new engine saturates for every open chain \(2\le n\le32\) and every ring
\(3\le n\le32\):

| layer | computed range | modular dimension | saturation first reached |
|---|---:|---:|---:|
| open chain | \(2\le n\le32\) | \(n^2\) | \(k=2n-1\) |
| ring | \(3\le n\le32\) | \(3n-1\) | \(k=2n-1\) |

Representative complete profiles are

```text
open n=12:
2,3,5,7,11,14,19,23,29,34,41,47,55,62,71,79,89,98,109,119,131,142,144,144

ring n=12:
2,3,5,6,8,9,11,12,14,15,17,18,20,21,23,24,26,27,29,30,32,33,35,35
```

Before the boundary is felt, open-chain increments grow only linearly with depth, so
\(D_k=O(k^2)\); ring increments are bounded and \(D_k=O(k)\).  This is the polynomial control
against which the grid profiles should be compared.

**Proof status.**  Equality for all \(n\) is not claimed as a theorem here.  It is exact modular
computation through \(n=32\), at both stored control primes for the regression cases.  There is,
however, a clean analytic upper bound for the open chain.  With Jordan--Wigner Majoranas,

\[
 X_j=i\gamma_{2j-1}\gamma_{2j},\qquad
 Z_jZ_{j+1}=i\gamma_{2j}\gamma_{2j+1}.
\]

Thus \(A,B\) map to the alternating-edge sums in \(\mathfrak{so}(2n)\).  On the one-particle
space define

\[
 J e_r=(-1)^{r-1}e_{2n+1-r}.
\]

Then \(J^2=-I\), and direct substitution shows that both alternating-edge sums commute with
\(J\).  Their algebra is contained in the centralizer of this orthogonal complex structure,
which is \(\mathfrak u(n)\) and has real dimension \(n^2\).  This proves
\(\dim\langle A,B\rangle\le n^2\) for every open chain; the computations certify equality for
\(n\le32\).  This note does not supply the missing all-\(n\) generation argument, nor an all-\(n\)
proof of the ring formula.

### 3.2 Grids

| \(2\times2\) | 11 | 11 |
| \(2\times3\) | 263 | 263 |
| \(2\times4\) | 2952 | 2952 |
| \(3\times3\) | **8034** | **8034** |

The \(3\times3\) calculation now completes.  Its point-group orbit support has 8739 columns,
split into blocks of sizes `(2112, 2160, 2355, 2112)`.  The generated block ranks are
`(1962, 1963, 2147, 1962)`, summing to 8034.  At both primes the complete profile is

Thus \(\dim_{\mathbb Q}\langle A,B\rangle\ge8034\) rigorously.  The identical fixed point at two
31-bit primes is the reported finite-field dimension; a separate rational upper certificate of
8034 was not found.

## 4. Growth rate and the finite ladder certificate

A fixed finite layer must eventually saturate, so no late-depth fit should be interpreted as an
asymptotic law.  The script uses one declared descriptive rule: fit the last at most eight rising
points before the first post-depth-5 ratio below 1.1.  All logarithms and regressions use
`mpmath` at 50 decimal digits.

For the unsaturated or pre-taper grid windows, \(\log D_k\) is nearly linear in \(k\): the
recorded bases per bracket depth are about 1.5--1.6, with log-linear \(R^2\) close to one.  In
particular, the \(2\times5\) dense run through \(D_{19}=4588\) gives base 1.567883 on depths 12--19
with \(R^2=0.999508\); the \(3\times3\) pre-taper window gives 1.5523.  This contrasts with the
explicit linear/quadratic depth profiles in one dimension.  These are descriptive finite-depth
rates, not proofs of an infinite-family exponent.

There is a rigorous **finite computer-assisted certificate** for ladders.  Exact modular ranks at
depth \(2L\) give

| \(L\) | \(D_{2L}(2\times L)\) | \(2^L\) |
|---:|---:|---:|
| 2 | 6 | 4 |
| 3 | 16 | 8 |
| 4 | 38 | 16 |
| 5 | 85 | 32 |
| 6 | 197 | 64 |

Hence \(\dim\langle A,B\rangle\ge D_{2L}\ge2^L\) is rigorously certified for every computed
\(L=2,\ldots,6\).  This is not an induction and **does not prove** the inequality for all \(L\).
No explicit infinite family of leading Pauli orbit sums was isolated, so exponential growth of the
entire infinite ladder family remains a conjecture supported by the exact finite profiles.

Using only the three completed ladder totals gives successive size ratios \(263/11\) and
\(2952/263\); the endpoint geometric base is
\((2952/11)^{1/2}=16.381808092016\) per added rung.  With only three completed sizes this number is
a descriptive finite-size estimate, not an asymptotic growth constant.

## 5. Memory and time walls

The table below is **after** point-group orbit reduction.  “Graded square” is the number of bytes
needed to allocate every possible `int32` echelon row in all four grading blocks.

| layer | orbit columns | grading block columns | unblocked square | graded square |
|---|---:|---|---:|---:|
| \(2\times4\) | 4,128 | 1088, 992, 1024, 1024 | 68,161,536 B | 17,059,840 B |
| \(3\times3\) | 8,739 | 2112, 2160, 2355, 2112 | 305,480,484 B | 76,530,852 B |
| \(2\times5\) | 66,304 | 16832, 16320, 16576, 16576 | 17,584,881,664 B | 4,396,744,704 B |
| \(2\times6\) | 1,049,088 | 263168, 261632, 262144, 262144 | 4,402,342,526,976 B | 1,100,590,612,480 B |
| \(3\times4\) | 1,052,672 | 264192, 262144, 263168, 263168 | 4,432,473,358,336 B | 1,108,126,728,192 B |

The workstation has 103,079,215,104 physical bytes.  Thus the fully allocated graded dense
matrices for \(2\times6\) and \(3\times4\) require about 1.10 TB and are decisively beyond this
machine; their depth profiles use the sparse engine instead.

For \(2\times5\), the 4,396,744,704-byte graded allocation fits.  A bounded 300-second dense run
completes every rank through \(D_{19}=4588\), then certifies \(D_{20}\ge7183\) before its time wall.
At the wall it uses 475,507,968 basis bytes and has observed peak RSS 574,029,824 bytes.  These
values are recorded in `results/algebra_growth/exact_dimensions.json`.  The calculation did
**not** saturate, so no total \(2\times5\) dimension is claimed.
