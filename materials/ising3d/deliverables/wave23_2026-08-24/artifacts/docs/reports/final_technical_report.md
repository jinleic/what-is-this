### 3.1 Theorem DG — the closed-form Dolan–Grady defect
`proofs/dolan_grady_defect.md`; verified term-by-term on 16 graphs by
`experiments/e16_dg_theorem_check.py`.

For `A = sum_v X_v`, `B = sum_{(ij) in E} Z_iZ_j` on any finite simple graph:

    (i)  [A,[A,[A,B]]] - 16[A,B] = 0     identically, for every graph;

    (ii) [B,[B,[B,A]]] - 16[B,A]
          = 24i sum_v Y_v [ (deg v - 2) sum_{u~v} Z_u
                          + 2 sum_{{u,u',u''} subset N(v)} Z_u Z_{u'} Z_{u''} ] .

Consequences: the residual vanishes iff every vertex has degree `0` or `2`; its **quartic part**
vanishes iff `Delta <= 2`; and the number of quartic terms is exactly `sum_v C(deg v,3)`, which is
exactly the number of induced claws in the frustration graph.

**Quartic defect density**: `0` for a 1D layer (any boundary condition), exactly `4` per bulk site
for a 2D layer. *This is the precise, quantitative answer to "what fails in three dimensions":
not the lattice dimension, but the layer coordination number, entering through one binomial
coefficient.* The DG2 residual is **4-local in the Pauli presentation** — no cubic term appears,
nothing higher at this order, and the 4-site monomial count is exact. This is a statement about
the Pauli basis; it is not a proof that a minimal fermionic extension is quartic, since
4-locality in Pauli strings does not determine fermionic body order under Jordan-Wigner.

### 3.2 Theorem TD — no tridiagonal relation
`proofs/tridiagonal_nogo.md`; `experiments/e21`–`e23`.

The tridiagonal (Askey–Wilson) relations contain Dolan–Grady as the single point

solvability is decidable exactly. An affine-completeness lemma (proved) shows that

    every cycle (2-regular layer, 2D Ising)     ->  IS a tridiagonal pair; C_6..C_9 give (2,0,16)
    every torus layer 3x3..5x5 (3D Ising)       ->  NO SOLUTION, for any parameters

Both sides are boundaryless and translation invariant, so the comparison has no boundary confound.

### 3.3 Theorem 11 — there are no conserved fluxes
`proofs/algebraic_obstruction.md` §5; `experiments/e27_flux_sectors.py`.

        lambda_1 * lambda_2 / lambda_0   MUST be an eigenvalue.
