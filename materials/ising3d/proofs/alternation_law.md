`n = 2L` single-site strings `X_i` and the `3L - 2` open-bond strings `Z_u Z_v`, inside `gl(2^n)`.
Write Pauli strings as `(x|z) in F_2^{2n}` (C16 convention; phases irrelevant over Q). Then:

**Set law** [THEOREM at L <= 4, CONJECTURE all L].

```
g_L = { (x|z) : z even-weight, z != J,  (J - z) . x = 1 + z . d }
        union  (L odd only)  { (x|J) : x arbitrary },
```

where `J = 11...1` and `d` is either checkerboard (2-colour) class of the ladder bipartition
(the choice is gauge: for even-weight z the functionals z.d and z.(J xor d) coincide).

**Dimension law** [THEOREM at L <= 4 from the set law; matches all other known points].

```
dim g_L = 2^(n-1) * ( 2^(n-1) - (-1)^L )
        = 2 * 2^(n-2) * (2^(n-1) - 1)   (L even)  = 2 dim so_{2^(n-1)}
        = 2 * 2^(n-2) * (2^(n-1) + 1)   (L odd)   = 2 dim sp_{2^(n-1)}
```

**Type law** [THEOREM at L <= 4 via C16/e148 certificates].

```
g_L ~= so_(2^(n-1))(Q) (+) so_(2^(n-1))(Q)   (L even; D-series, split)
     ~= sp_(2^(n-1))(Q) (+) sp_(2^(n-1))(Q)   (L odd;  C-series, split),
```

with the splitting on the two `prod-X` parity halves and the invariant form on each half the
**same** signed checkerboard matching `s <-> s xor d` (identical sha256 of B+ and B- in
results/algebra/char0_2x4.json). The form is symmetric (L even) / alternating (L odd), and its
sign law, rediscovered by the wave-16 front agent as "F^T = (-1)^L F", is exactly the statement
that the matching involution (with its signs) squares/symmetrizes to `(-1)^L`.

## 4. Wave-17 lemma: the forward closure direction (gap a, part 1) for all L

**[LEMMA 4.1]** For every `L >= 2`, `S_law` is closed under the adjoint action of the 2xL
generators `X_i` and `Z_u Z_v`: if `s in S_law` and `[g, s] != 0`, then `g.s in S_law`.
Proof (uniform, three cases; `z.d` is well-defined on even-weight z because `d ~ J+d` there):

1. **X-generators** (`g = (e_i, 0)`): the product has the same `z`; the law's condition
   `(J-z).x = 1 + z.d` under `x -> x+e_i` changes iff `(J-z)_i = 1`. But `[X_i, s] != 0`
   iff `z_i = 1` iff `(J-z)_i = 0`, so membership is invariant. Closed.
2. **Bond generators** (`g = (0, e_u+e_v)`, `z + z_g != J`): z stays even-weight. From
   `s in S_law` (`(J-z).x = 1 + z.d`) the condition for `(x, z+z_g)` reduces to
   `z_g.x = z_g.d`. Nonzero commutator forces `symp = x.z_g = 1`, and every bond of the
   bipartite 2xL grid has exactly one endpoint in the checkerboard class `d`, i.e.
   `z_g.d = 1` identically. Membership preserved. Closed.
3. **Bond generators with `z + z_g = J`**: `z = J - z_g`, and the law gives
   `x_u + x_v = z_g.x = 1 + z.d = 1 + |d| - z_g.d = L (mod 2)` (using `|d| = L`,
   `z_g.d = 1`). Hence `symp = x.z_g = L (mod 2)`. For L even the commutator VANISHES
   (no escape from the closed set, which excludes `z = J`); for L odd the product lands on
   `z = J`, which the L-odd fiber includes with all `x`. Consistent either way. Closed.

`square` This is one of the two halves of gap (a); combined with the L<=5 exact set
certificates it gives: for every L, `g_L (= Lie closure) subseteq span(S_law)`. The
reverse inclusion (every law string is generated) remains the open saturation step; the
affine structure used in case 3 is exactly the induction hook for it.

## 5. Wave-17 lemma: basis-set closure (pull-back principle)

**[LEMMA 5.1]** Let `R` be the generator-monotone closure set (start: generators; step: if
`s in R` and `g` a generator with `symp(s,g)=1`, adjoin the product string `s.g`).

(a) `span_Q(R) = g_L` (ad-generators generate the algebra; Pauli strings form a basis, so the
    monotone set suffices).
(b) `R` is closed under ALL symplectic products of its own elements: if `s1, s2 in R` and
    `symp(s1,s2) = 1` then `s1.s2 in R`. Proof: `[s1,s2] = ±2 s1.s2` is a nonzero element of
    `g_L = span(R)`; Pauli strings are linearly independent, and `±2 s1.s2` is a single basis
    string up to scalar; hence that string (phase-fixed) lies in `R`. `square`

Corollary: reachability arguments may freely multiply any two previously reached strings with
odd symplectic pairing; the three-case membership checks of Lemma 4.1 then only need to be
done for generator-steps (done there).

    g_{2xL}(Q)  SUBSETEQ  so_{2^{n-1}}(Q) (+) so_{2^{n-1}}(Q)   (L even)
                SUBSETEQ  sp_{2^{n-1}}(Q) (+) sp_{2^{n-1}}(Q)   (L odd),

*Proof.* (1) Set-containment and the dimension upper bound: Theorem 7.1(partial). (2) **Form membership is exactly the set

    |x|  ==  1 + z.x + z.d      (mod 2)          ... (*)
