# Quant trading explorations

This is the campaign target for falsification-first quantitative-trading research.

Canonical state is split deliberately:

- `strategy-registry.json` owns registered directions, verdicts, artifact routing, and the current conclusion.
- `../workspace.json` owns domain routing, lawful-data constraints, and the active next action.
- `state.json` is the generated cold-start summary; it is not an authority over either owner above.
- `campaigns/README.md`, when present, is generated by `scripts/campaign.py` from frozen run evidence.

New mechanisms must be genuinely distinct from every closed family. Before any outcome access: enumerate prior consumed windows with file and field citations, obtain independent read-only review, and mint the run with `scripts/campaign.py init`. Never overwrite frozen run files or rescue a failed rule by tuning, pooling, extending, or changing its window.
